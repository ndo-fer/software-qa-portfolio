# Fernando Michael Panjaitan — QA Portfolio

This repository is a clean-room QA portfolio built with public applications and synthetic test data. It is being developed incrementally so that each published claim is supported by an inspectable artifact.

## Portfolio Projects

### 1. E-Commerce QA Case Study

Manual QA discovery and test design for the public nopCommerce Demo storefront. Sprint 1 is currently in progress; automation has not started.

### 2. Legacy ERP Migration Analysis

Planned clean-room case study covering domain familiarization, business-flow reconstruction, requirement analysis, and test derivation.

### 3. REST API Testing

Planned public-API case study covering positive, negative, validation, and CRUD testing.

### 4. Selenium Case Study

Optional secondary UI automation project planned only after the primary portfolio projects.

## Current Milestone

Sprint 1 — Repository setup and e-commerce discovery.

## Working Principles

- Separate observation, approved requirements, assumptions, and open questions.
- Never fabricate test results, defects, evidence, or environment coverage.
- Base expected behavior only on an approved portfolio requirement, clearly supported public product behavior, or an explicit human decision.
- Treat behavior without sufficient support as needing clarification.
- Introduce automation only after the manual QA foundations are reviewed.
